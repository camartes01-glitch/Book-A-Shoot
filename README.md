# Book-A-Shoot

A small full-stack **photography session booking** app. Browse photography
packages (portrait, wedding, event, product), pick a date, and reserve a shoot —
bookings are persisted and listed live.

Built as a demonstration of a fully working Cursor Cloud Agent development
environment.

## Tech stack

| Layer    | Tech                                                        |
| -------- | ----------------------------------------------------------- |
| Frontend | React 18 + Vite + TypeScript                                |
| Backend  | Node.js + Express + TypeScript (`tsx`)                      |
| Database | SQLite via `better-sqlite3` (file-based, no external deps)  |
| Tooling  | npm workspaces, `concurrently`                              |

The repo is an npm workspace with two packages:

- `server/` — REST API on port **3001** (SQLite storage, seeded catalog).
- `client/` — Vite dev server on port **5173**, proxying `/api` to the server.

## Getting started

```bash
npm install     # install all workspace dependencies
npm run seed    # create/seed the SQLite catalog (idempotent)
npm run dev     # run API (:3001) and web (:5173) together
```

Then open http://localhost:5173.

### Other commands

```bash
npm run build         # type-check + build both workspaces
npm run dev:server    # run just the API
npm run dev:client    # run just the web client
```

## API

| Method   | Endpoint             | Description                       |
| -------- | -------------------- | --------------------------------- |
| `GET`    | `/api/health`        | Health check                      |
| `GET`    | `/api/packages`      | List photography packages         |
| `GET`    | `/api/bookings`      | List bookings (newest first)      |
| `POST`   | `/api/bookings`      | Create a booking (validated)      |
| `DELETE` | `/api/bookings/:id`  | Cancel a booking                  |

`POST /api/bookings` body:

```json
{
  "packageId": 2,
  "customerName": "Ada Lovelace",
  "customerEmail": "ada@example.com",
  "sessionDate": "2026-10-15",
  "notes": "Golden hour by the pier"
}
```

## Cloud Agent environment

`.cursor/environment.json` configures the Cloud Agent dev environment:

- **install:** `npm install --no-audit --no-fund && npm run seed`
- **terminals:** `api` (`npm run dev:server`) and `web` (`npm run dev:client`)
- **ports:** `5173` (web), `3001` (api)

The SQLite database lives at `server/data/book-a-shoot.db` and is regenerated by
the seed script, so it is git-ignored.
